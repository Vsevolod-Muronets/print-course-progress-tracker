# Трекер прогресса по курсам

Приложение для студентов, в котором каждый студент ведет свои курсы (дисциплины) с формулой оценки, дедлайны заданий внутри курсов и административные обязанности (также с дедлайнами). Для каждого курса приложение показывает накопленные баллы и оценку.

За основу взят пример с занятия `app_final.py`.

## Окружение и зависимости

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Запуск приложения

```bash
cp .env.example .env
python -m uvicorn app_final:app --env-file .env
```

Документация API: http://127.0.0.1:8000/docs

Команда выше - обычный запуск без `--reload`. Флаг `--reload` нужен только при разработке.

Данные сохраняются в файле `data.json` после каждого изменения и читаются при следующем запуске. Путь к файлу задает переменная `DATA_FILE`, папка в этом пути должна существовать. Создавать сам файл заранее не нужно.

Сначала нужно создать студента (`POST /students`), остальные маршруты находятся под `/students/{student}`, например `/students/{student}/courses`. Полный список маршрутов - в `/docs`.

## Запуск тестов

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -v
```

## Переменные окружения

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `PROGRAM_NAME` | Название учебной программы, общей для всех студентов: в `/`, заголовке `/docs` и логе запуска | `Программа обучения` |
| `STUDY_YEAR` | Курс обучения: в ответе `/` | `1` |
| `DATA_FILE` | Файл, в котором сохраняются курсы, задания и обязанности | `data.json` |

## Проверка и диагностика

```bash
curl http://127.0.0.1:8000/health
curl http://127.0.0.1:8000/version
```

Ожидаемые ответы: `{"status":"ok"}` и `{"version":"0.1.0"}`.

Логи выводятся в терминал, где запущен сервис: запуск, загрузка данных, создание студента и курса, добавление и выполнение заданий, закрытие элемента оценивания, обязанности.

Если что-то не работает:

- `ModuleNotFoundError` - не активировано окружение или не установлены зависимости.
- `Path '.env' does not exist` - создайте файл командой `cp .env.example .env`.
- `address already in use` - порт занят, запустите с `--port 8001`.
- Название программы не изменилось - проверьте, что файл `.env` лежит рядом с `app_final.py`, в нем нет опечаток, а сервис запущен с `--env-file .env`.
- Сервис не запускается с ошибкой `JSONDecodeError` - файл `data.json` поврежден, исправьте его или удалите.
- Ответы `404`, `409`, `422` - причина указана в поле `detail` тела ответа.
- Тесты упали - читайте вывод pytest сверху вниз, сначала имя упавшего теста, потом сравнение ожидаемого и полученного значения.
